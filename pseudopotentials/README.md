# Pseudopotentials

PBE PAW datasets from the JTH v2.0 table (F. Jollet, M. Torrent and
N. Holzwarth), used for all calculations: Al, B, C, Er, H, N, O, P and Si. Each
file is the unmodified `<El>.GGA_PBE-JTH.xml` from
`JTH-v2.0-GGA-PBE-atomicdata-xml.tar.gz`, renamed to `<El>.xml`.

- Source: https://www.abinit.org/atomic_data/paw/ and
  https://github.com/abinit/paw_jth_datasets
- License: GNU General Public License v3.0 (`LICENSE` in this directory)
- Reference: F. Jollet, M. Torrent and N. Holzwarth, *Comput. Phys. Commun.*
  **185**, 1246 (2014)
